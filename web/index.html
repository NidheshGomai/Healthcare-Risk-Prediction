Chapter 1

The data that can't move

Every ICU collects the signals that predict who is at risk of dying: age, organ-failure scores, blood gases, blood pressure. But privacy law (HIPAA in the US, GDPR in Europe) and plain ethics stop hospitals from copying those records into one central database.

So each hospital trains on its own patients. The trouble is that patients, protocols and equipment differ from site to site. A model that looks fine at home can stumble a few kilometres away. The question this project asks is simple: can hospitals get the benefit of each other's data without ever seeing it?

    How the data was prepared (CO1)
    1. Imputation: median for continuous vitals and labs, mode for categorical variables.
    2. Range clipping: physiologically impossible values (for example heart rate outside 20–250) clipped to remove telemetry artefacts.
    3. Scaling: Z-score and Min-Max, fitted only on each hospital's own training data, so nothing leaks.
    4. Discretisation: 10 quantile bins per feature for Categorical Naïve Bayes.
    5. Partitioning: data split by hospital to preserve the natural non-IID structure.

    Chapter 2

    Move the model, not the data

    Federated learning flips the usual pipeline. Scroll through one round.

    01

    Each hospital trains at home

    Every site preprocesses its own records and grows its own models: 50 decision trees for the random forest, or simple counts and sums for Naïve Bayes. Patient records never leave the building.

    02

    Only the learning travels

    What goes to the server is the result of learning: fitted trees, or sufficient statistics such as class counts, feature sums and sums of squares. These can be noised with differential privacy and masked with secure aggregation first.

    03

    The server combines them

    Forest Union pools all 5 × 50 trees into a single soft-voting ensemble. For Naïve Bayes the server adds up the statistics, which rebuilds exactly the model you'd get from centralised training.

    P(y=1 | x) = Σc Σm wc,m · Pc,m(y=1 | x)

    04

    Everyone gets the global model

    The combined model goes back to every hospital. Each one now benefits from patterns learned across all five sites, though none of them ever saw another site's patients.

    Why would federated beat centralised?

    Normally pooling all data is the ceiling. Here, trees grown independently on five different hospital distributions act like a distributed bagging ensemble: each forest makes different mistakes, and soft-voting across 250 trees averages them out. Model variance falls further than a single forest trained on the pooled data.

    The tree-weighting strategy barely matters, which suggests the gain comes from diversity rather than tuning.

    Chapter 4

    The price of privacy

    Sending statistics instead of records isn't enough on its own: a clever attacker can sometimes work backwards from them. Two defences close that gap.

    Differential privacy: AUROC vs privacy budget ε

    Laplace noise with scale Δf / ε is added to every statistic a hospital sends. Smaller ε means more noise and stronger privacy. Each point is the mean of 3 trials; the band shows ± 1 std.

    Gaussian NB Categorical NB Sweet spot (ε 5–10)
    0.10.512510∞

    Secure aggregation: the server sees only the sum

    Each pair of hospitals agrees on a random mask. One adds it, the other subtracts it. Each individual upload looks like noise, but when the server adds all uploads together every mask cancels, leaving the exact true total.

    Try it: shuffle the masks. The uploads change completely, but the sum never moves.

    Chapter 5

    Opening the black box

    A risk score a clinician can't question is a risk score they won't use. Each hospital computes Gini and TreeSHAP importances locally; only those summaries are aggregated.

    What drives the prediction

    Federated feature attribution, top 7 features

    The model agrees with medicine

    The top drivers are age, the SOFA organ-failure score and the APACHE acuity score, followed by acid-base markers (bicarbonate, pCO₂) and blood pressure. These are the same signals intensivists already use to triage, which is a basic sanity check that the model learned physiology rather than artefacts.

      CO4 · Clustering

      Finding patient subgroups, federated

      K-means picked k = 5 subgroups using the elbow and silhouette methods. In the federated version, each hospital shares only per-cluster counts and coordinate sums, and the server updates the centroids.

      μk = Σc Sc,k / Σc nc,k

      A low ARI and silhouette show that subgroup structure in this cohort is weak. That's an honest finding, and a direction for future work.
